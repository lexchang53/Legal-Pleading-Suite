# Markdown 映射規則

定義通用 Markdown 語法如何映射至 Word 樣式與編號。

## 映射對照表

| Markdown 語法 | Word 樣式 | numId | ilvl | 說明 |
|---------------|-----------|-------|------|------|
| `# 標題` | Heading 1 | - | - | H1 標題 |
| `## 標題` | Heading 2 | - | - | H2 標題 |
| 以 `一、` 開頭 | 通用_層級1 | 動態 | 0 | 自動識別並轉換為第一層大綱 |
| 以 `(一)` 或 `（一）` 開頭 | 通用_層級2 | 動態 | 1 | 自動轉換為第二層大綱 |
| 以 `1.` 開頭 | 通用_層級3 | 動態 | 2 | 自動轉換為第三層大綱 |
| 以 `(1)` 開頭 | 通用_層級4 | 動態 | 3 | 自動轉換為第四層大綱 |
| 無前綴普通文字 | Normal | - | - | 預設正文樣式 |

## 粗體控制原則

- **標題粗體**：`一、` (通用_層級1) 的粗體效果由排版腳本自動控制（或繼承樣式定義）。
- **行內粗體**：Markdown 中的 `**粗體文字**` 標記會被轉換為 Word 的 run-level bold，標記符號不殘留在正文中。

## 論述段落自動縮排

當標題段落（`通用_層級1~4`）後方緊接普通文字段落時，腳本會自動將該段落縮排至父標題的文字起始點。

| 父標題層級 | 縮排量 (twips) | 說明 |
|-----------|---------------|------|
| `一、` | 567 | 對齊「一、」後方 |
| `(一)` | 850 | 對齊「(一)」後方 |
| `1.` | 850 | 對齊「1.」後方 |
| `(1)` | 1134 | 對齊「(1)」後方 |

## 層級前綴匹配規則

解析器使用正規表達式匹配行首：
- `1. /^([一二三四五六七八九十]+、)/` → `通用_層級1`
- `2. /^[\(（]([一二三四五六七八九十]+)[\)）]/` → `通用_層級2`
- `3. /^(\d+)\.\s/` → `通用_層級3`
- `4. /^\((\d+)\)\s/` → `通用_層級4`

匹配後，前綴將從段落文字中移除，改由 Word 自動編號產生。

## 範例

```markdown
# 專案執行計畫大綱

一、背景說明
二、目標設定
(一) 階段性目標
1. 建立核心排版引擎
2. 支援多層次編號
(1) 支援中文數字
(2) 支援阿拉伯數字
(二) 測試與驗證

三、預期效益
此計畫旨在提供一個純粹的大綱排版工具，減少人工調整格式的時間。
```
